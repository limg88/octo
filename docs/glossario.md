# Glossario dell'interfaccia

Le parole che Octo usa con chi lo usa. Una cosa ha un nome solo; i nomi tecnici restano nel codice.

| Si dice | Vuol dire | Non si dice |
|---|---|---|
| progetto | una cartella del computer che Octo legge | vault, workspace |
| sezione | una voce della colonna di sinistra (Chiedi, Ore…) | scheda, tab |
| fonte | ciò che alimenta il progetto: posta, un sistema, i documenti | feed, connettore |
| collegare, scollegare | dare o togliere a Octo l'accesso a una fonte | configurare, linkare |
| leggere | portare nel progetto ciò che una fonte contiene | sincronizzare, importare |
| voce | un elemento del tracker del cliente (bug, storia, attività) | work item |
| ticket | un elemento del proprio tracker | issue |
| tracker | lo strumento dove stanno voci o ticket | ALM, board |
| timesheet | le ore dichiarate e approvate nel gestionale | — |
| ore del tracker | le ore segnate sui ticket | worklog |
| commessa, codice di progetto | il codice del gestionale, «PRJ» e sei cifre | project id |
| esportazione | un file con ciò che un sistema contiene a una certa data | export, snapshot, dump |
| archivio dei dati aziendali | da dove si leggono ore, ordini e fatture di NetSuite | data warehouse, DWSI |
| token | la credenziale personale di un sistema | PAT, API key |
| modello Excel, modulo | il file dell'amministrazione o del cliente che Octo compila | template |
| Claude (quale Claude lavora) | il modello che risponde, scrive e rilegge | modello (da solo) |
| deliverable | un testo o un file che esce dal progetto | output, artefatto |
| istruzioni | come un deliverable va scritto | prompt |
| impostazioni | ciò che si scrive una volta | configurazione, settings |

Regole:
- Octo parla in prima persona («Leggo…», «Non ho salvato…») e dà del tu.
- Un errore dice che cosa manca e dove si rimedia; mai «qualcosa non ha funzionato» se si sa che cosa.
- Niente estensioni di file, percorsi interni o sigle nelle etichette: stanno, se servono, in un aiuto.
