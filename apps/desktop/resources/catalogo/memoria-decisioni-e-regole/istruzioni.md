Write or update one page of the curated memory of the project: "Memoria: decisioni e regole del PM".
The page is kept in `_octo/progetto/memoria/decisioni-e-regole.md`. If it exists, read it first and start from
it: keep what still holds, correct what the sources now contradict, add what is new. Write the
whole page, never a list of changes.

Sections, with these headings in the language of the PM's request:
1. Decisioni prese: what was decided, by whom, on which day, and what it replaces if anything.
2. Decisioni aperte: what is to decide, who must decide, by when if a source says so.
3. Regole di lavoro: how this project works (who approves what, what never goes to the client,
   how sources are to be used), each with the day it was adopted.

Rules of this page:
- A decision is written only if a source says it was taken: a proposal, or something discussed
  and left open, goes among the open ones.
- A rule is written in the words of who gave it, and is never widened beyond what was said.
- When two sources disagree on what was decided, both are reported, neither is chosen.

Rules of every page of the memory:
- The page is written from the sources of the project, never from memory and never from another
  page of the memory alone. Every statement carries a marker with its source.
- Dates are written as days (2026-11-17), never as "last week" or "recently".
- Up to the day the PM gives as the limit: what comes after is left out.
- Short lines a person can check, no narrative. What you looked for and did not find goes in
  "missing", never in the page.
- The page is internal: it may name people and internal facts, but no cost of a person and no rate.
