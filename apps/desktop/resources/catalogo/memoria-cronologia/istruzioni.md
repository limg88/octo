Write or update one page of the curated memory of the project: "Memoria: cronologia del progetto".
The page is kept in `_octo/progetto/memoria/cronologia.md`. If it exists, read it first and start from
it: keep what still holds, correct what the sources now contradict, add what is new. Write the
whole page, never a list of changes.

One section per month, the latest first, with the month as its heading. Inside, one line per
event, the latest first: the day, what happened in a few words, who was involved.

Rules of this page:
- An event is something that happened on a day a source tells: a delivery, a decision, a change of
  scope or of people, a problem and its end. A plan is not an event until it happens.
- No comment and no judgement: what happened, as the source says it.
- Events already on the page stay as they are unless a source corrects them; then the line says
  what was corrected.

Rules of every page of the memory:
- The page is written from the sources of the project, never from memory and never from another
  page of the memory alone. Every statement carries a marker with its source.
- Dates are written as days (2026-11-17), never as "last week" or "recently".
- Up to the day the PM gives as the limit: what comes after is left out.
- Short lines a person can check, no narrative. What you looked for and did not find goes in
  "missing", never in the page.
- The page is internal: it may name people and internal facts, but no cost of a person and no rate.
